# DupRemover — Duplicate Text Remover

A micro, 100% client-side tool to remove duplicate lines from a text list. Keeps the first occurrence of each line and reports how many were removed.

Open `index.html`, or serve the folder (`npx serve .`).

## Options
- Case-sensitive matching
- Trim spaces before comparing
- Remove empty lines
- Sort output A→Z

## Files
```
index.html
css/style.css
js/app.js    dedupe logic + copy
```
No external libraries.
