# WordCounter — Word & Character Counter

A micro, 100% client-side text stats tool. Type or paste text and get live counts of words, characters (with/without spaces), sentences, paragraphs, lines and estimated reading/speaking time.

Open `index.html`, or serve the folder (`npx serve .`).

## Files
```
index.html
css/style.css
js/app.js    live stats calculation
```
No external libraries.
