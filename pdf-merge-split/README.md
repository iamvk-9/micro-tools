# PDFMergeSplit — Merge & Split PDFs

A micro, 100% client-side tool to merge multiple PDFs into one, or split a PDF into single pages and page ranges. Nothing is uploaded.

Open `index.html`, or serve the folder (`npx serve .`).

## Features
- **Merge**: drop PDFs in order, re-order/remove, output a single merged PDF
- **Split**: one file per page, or extract a specific page range

## Files
```
index.html            merge/split tabs
css/style.css
js/app.js             merge + split logic
libs/pdf-lib.min.js   PDF manipulation
```
