# TextCase — Text Case Converter

A micro, 100% client-side text case converter. Paste text and convert between uppercase, lowercase, title case, sentence case, camelCase, PascalCase, snake_case, kebab-case, inverse and alternating case. Copy the result in one click. Nothing leaves your device.

Open `index.html`, or serve the folder (`npx serve .`).

## Converts to
- UPPERCASE, lowercase, Title Case, Sentence case
- camelCase, PascalCase, snake_case, kebab-case
- InVeRsE and aLtErNaTiNg
