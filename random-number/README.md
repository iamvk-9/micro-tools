# RandNum — Random Number Generator

A micro, 100% client-side random number generator using the browser's crypto API. Pick a range, choose how many numbers, and whether duplicates are allowed.

Open `index.html`, or serve the folder (`npx serve .`).

## Features
- Any integer range
- Optional "no duplicates" mode
- Generate multiple numbers at once, copy the result

## Files
```
index.html
css/style.css
js/app.js    crypto-random generation + copy
```
No external libraries.
